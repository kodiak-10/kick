# Quiet Surprise Site

一个中文单页互动网页，定位是“给一个正在聊天的女生的小惊喜页面”。

## 运行方式

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看页面。

## 技术栈

- Next.js App Router
- React
- Tailwind CSS
- Framer Motion

## 页面内容

- 首屏柔和入场
- 点击后触发“今日限定彩蛋”揭晓动画
- 三张可重复点击、随机切换内容的互动卡片
- 结尾按钮支持“我看完了 / 再看一遍”
- 右上角隐藏星星彩蛋
